Aplicativo Android desenvolvido em Java para apresentar o curso superior de **Desenvolvimento de Software Multiplataforma (DSM)** da FATEC Diadema – Luigi Papaiz.



## **Funcionalidades**



**Sobre o Curso:** apresenta os conteúdos estudados, perfil profissional, áreas de atuação e dados da oferta do curso em Diadema.

**Vestibular:** explica as etapas do processo seletivo, apresenta o calendário do 1º semestre de 2027, dicas e acesso aos sites oficiais.

**Vídeo Institucional:** reproduz o vídeo fornecido usando `VideoView`, com capa de pré-visualização e controles para reproduzir, pausar e parar.

**Navegação:** as telas são conectadas com `Intent` explícitos.



## **Tecnologias utilizadas**



* Java.
* Android Studio.
* XML para as interfaces.
* `Intent` para navegação entre Activities.
* `VideoView` para reprodução de mídia local.
